# Online Shoe Store React App

## Project Description

This is a simple online shoe store application built using React.
Users can view available shoes, add shoes to the cart, remove items, and see the total cart price.

## Features

* Display available shoes with name, price, and image
* Add shoes to shopping cart
* Increase quantity when adding the same shoe again
* Remove shoes from cart
* Calculate total cart amount
* Responsive design for mobile and desktop

## Technologies Used

* React JS
* JavaScript
* CSS
* Vite

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies:

```
npm install
```

4. Start the project:

```
npm run dev
```

5. Open the given localhost link in the browser.
